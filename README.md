# TERRANEX ATLAS / WORLD 000 — The Open Source Universe (v0.4)

> **"나는 판을 깐다. 너희가 경쟁한다."**  
> TERRANEX는 오픈소스 프로젝트가 기술력을 증명하고 도전하는 공개 경쟁 및 검증 플랫폼입니다.

---

## 📌 v0.4 주요 기능 및 상태

기존 v0.2~v0.3의 단순 조회 기능을 넘어, **실제 상호작용이 가능한 다중 사용자 참여형 v0.4 개발 버전**이 완성되었습니다.

### 1. 신규 구현 기능
- **회원가입 및 로그인**:
  - 사용자 등록, 간편 로그인, 다중 계정 빠른 전환 기능 지원
- **프로젝트 등록 및 조회**:
  - 자신의 오픈소스 프로젝트(저장소 URL, 설명, 기술 카테고리) 등록 및 목록 조회
- **기술 도전(결투) 신청**:
  - 도전자 프로젝트와 방어자 프로젝트 간 과제, 지표, 환경 합의안을 작성하여 공식 도전
- **방어자의 수락 및 거절**:
  - 방어자가 조건을 검토한 후 수락(`ACCEPTED`) 또는 사유를 명시하여 거절(`REJECTED`)
- **공격자의 결과·증거 제출**:
  - 테스트 결과 요약, 증거 URL, 원시 실행 로그, 제3자 재현 방법 제출
- **방어자의 결과 확인 및 공식 기록**:
  - 방어자가 증거와 재현 가능성을 검토한 후 승인하여 공개 장부(Ledger)에 영구 기록
- **하이브리드 데이터 아키텍처**:
  - Supabase 클라우드 데이터베이스 연동 지원 (`supabase/schema.sql` 제공)
  - Supabase 미연결 시에도 즉시 모든 기능을 체험할 수 있는 로컬 스토리지 에뮬레이션 엔진 내장

### 2. 절대 준수 원칙
- **점수, 순위, 가상 영토 이전 기능 배제**: 단일 숫자로 기술력을 왜곡하거나 영토를 빼앗는 시스템을 일체 구현하지 않습니다.
- **오픈소스 자치 운영**: 참가자가 직접 규칙을 수립하고 결과의 재현성을 검증합니다.

## 🛠 실행 방법

1. 저장소 루트의 `index.html`을 브라우저에서 직접 열거나, 로컬 웹 서버로 실행합니다:
   ```bash
   # 예: Python 내장 서버
   python -m http.server 8000
   ```
2. 브라우저에서 `http://localhost:8000` 접속
3. 우측 상단의 **[회원가입]** 또는 **[샘플 계정으로 시작]** 버튼을 눌러 계정을 생성/선택합니다.
4. **프로젝트 등록** → **도전 신청** → **계정 전환** → **수락** → **증거 제출** → **공식 기록** 순으로 전체 흐름을 테스트할 수 있습니다.
