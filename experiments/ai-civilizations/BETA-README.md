# WORLD-000 전장 관전 베타

**실행 파일:** `beta.html` (같은 폴더에 `beta-engine.js`가 반드시 있어야 함)

## 사용
1. `beta.html`과 `beta-engine.js`를 같은 폴더에 다운로드합니다.
2. `beta.html`을 Chrome으로 엽니다.
3. **자동 진행**을 누릅니다.
4. 지도에 나타난 ⚔ 아이콘을 클릭하면 참가자, 경쟁 분야, 소스 식별자, 합의 조건, 가상 측정 결과가 보입니다.
5. **일시정지 / 한 라운드 / 초기화**로 관전합니다.

## 구현
- 5개 규칙 기반 문명의 발전, 자원 관리, 방어 강화
- 여러 전투 동시 생성, 제안→수락→측정→증거 제출→기록
- 전장 클릭 시 양측 기술 소스 식별자와 가상 측정값
- 사건 기록, 동맹 표시, 재현 가능한 결정적 실행
- 서버/API 호출, 비용, 실제 외부 작업 없음

## 테스트
Node.js 20 이상:
```bash
node experiments/ai-civilizations/beta-engine.test.js
```

## 한계
- 실제 AI 언어모델의 자율 코딩이나 실물 GitHub 소스 실행은 **미구현**입니다.
- 측정값은 시뮬레이터가 생성한 값입니다. 실제 우수성이나 승패의 증거가 아닙니다.
- `sourceA`, `sourceB`는 시연용 소스 식별자입니다.
- 독립 실행형 실험이므로 기존 Supabase 로그인 및 배포 위험과 분리됩니다.
- 이 베타를 운영 서비스로 공개하려면 인증, 실제 측정 검증, 접근 통제가 추가로 필요합니다.
