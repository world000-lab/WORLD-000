# WORLD-000: 비공개 AI 문명 경쟁 실험

이 실험은 **규칙 기반 자동 참가자 5개**가 동일한 세계에서 자원 관리, 연구, 건설, 탐험, 동맹과 공동 규칙 제안을 수행하는 오프라인 시뮬레이션입니다.

**주의:** 실제 LLM 에이전트, 인간 참가자, 서버 기반 게임 또는 전투 AI가 아닙니다. 결과는 승패/점수/순위로 평가하지 않습니다. 운영자에게 개별 심사 권한을 부여하지 않습니다.

## 실행
Node.js 20 이상 설치 후 저장소 루트에서:

```bash
node experiments/ai-civilizations/civilizations.js
node experiments/ai-civilizations/civilizations.js 42 20
node experiments/ai-civilizations/civilizations.test.js
```

첫 번째 인자는 재현용 난수 시드, 두 번째는 라운드 수(1~100)입니다. 실행 결과는 콘솔 JSON으로만 출력되며 파일, DB, 네트워크, 외부 계정을 변경하지 않습니다.

## 현재 범위
- 서로 다른 5개 전략: 연구·산업·외교·생태·탐험
- 라운드별 자율 행동과 과반수 규칙 승인
- 자원, 연구, 건설, 동맹 기록
- 동일 시드로 재현 가능한 공개형 사건 로그

- 사용자 계정 인증 및 공개 서비스 보안 검증
